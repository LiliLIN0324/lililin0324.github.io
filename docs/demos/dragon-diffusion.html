六个值得讲的产品决策

KEY DECISIONS
DECISION 01

把算法接口抽象成 agent 配置协议

从"每个算法一个定制页面"到"一套可配置协议"。这是项目思维到平台思维的分水岭，也是后面训练中台能闭环的前提。

DECISION 02

删掉且 / 或逻辑，改用框选顺序判定

布尔运算对设计师是认知负担，实测误用率高。用"选择先后顺序"这个天然行为承载语义 —— 用交互解决逻辑问题。

DECISION 03

1.1 版本删掉自己引入的取景框

取景框跑了大半年，验证下来与「画面扩展」在用户心智里重叠。果断删除并入，多做一个概念就是判断失误。

DECISION 04

提示词增强按场景双策略分流

纯文生图走长系统提示词补全画面细节；局部重绘 / 图生图只走翻译短提示词，避免 LLM 过度发挥污染原图语义。

DECISION 05

训练参数只开放三个

Rank、Batch size、Epoch 之外全部固化。目标用户是设计师，约束比自由更有价值。

DECISION 06

制定图片 prompt 绑定规范

生成图复用原 prompt，上传图与编辑图走算法反推。保证任何图片二次输入时语义不丢失，是整条链路跑通的隐形前提。

Dragon Diffusion（新智图）｜AI 设计生产平台｜产品经理
2023.10 – 2024.09

面向专业设计师的 AI 创意生产平台，形态为「无限画布 + AI 工作台」，底层由推理 / 数据 / 训练三中台支撑。全程主导 0→1 及 16 个版本迭代。

  • C 端画布产品：定义 7 类画布元素体系与 AI 工作台交互模型，落地局部重绘、局部擦除、画面扩展、精细抠图、拖拽生图等 8 项图像编辑能力；0.4 版本将二次编辑由抽屉式重构为悬浮栏直达，操作路径由 3 步压缩至 1 步。
  • agent 平台化：设计 agent 配置协议，将算法接口抽象为「条件类型 + 条件命名 + 顺序判定」的规则模型，新算法上线由前端写死改为管理端配置即时生效；配套三大行业模板（通用 / 室内设计 / 海报设计），累计承载 30+ agent。
  • B 端中台：主导数据中台（数据仓库 Gallery、数据集版本血缘、5 项自动预处理、finetune / LoRA 双套打标）与训练中台（LoRA 训练任务调度、GPU 资源看板、模型仓库、多路模型对比广场）建设，打通「数据 → 训练 → 推理」闭环。
面试防守要点：设计背景是差异化而非短板 —— 「画布这类重交互产品，我能把交互逻辑直接定义到可开发颗粒度，中间不需要再翻译一层」。 必备的自黑答案是取景框（DECISION 03），必备的深挖答案是 agent 规则引擎（DECISION 01 / 02）。
